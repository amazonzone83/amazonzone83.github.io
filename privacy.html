Privacy Policy

eBay Product Research (Chrome extension) · last updated November 21, 2026

What this app is

A private Chrome extension used by its owner to research products and manage their own eBay listings. It is not offered to the public.

Google data it uses

When the user turns on Sync across computers, the extension asks for one Google permission: drive.appdata, which lets it read and write files in a hidden folder that belongs to this app in the user's own Google Drive. It cannot see, open or change any other file in the user's Drive. It also reads the signed-in account's email address only to keep the user signed in.

What is stored and where

The extension's own working data (product lists, sales records, settings and listing descriptions) is stored in the user's browser and, with sync on, in that hidden Drive folder. API keys and other per-computer settings are never uploaded.

Sharing

No data is sent to the developer or to any third party. Nothing is sold, shared or used for advertising. Google user data is used only to provide the sync feature.

Removing data

Turn sync off with Disconnect this computer in the extension. To delete the synced data, open Google Drive → Settings → Manage apps, find this app and choose Delete hidden app data, or remove its access at myaccount.google.com/permissions.

Contact

Questions: use the support email shown on this app's Google sign-in screen.
